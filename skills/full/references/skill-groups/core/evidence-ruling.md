# Core: evidence and ruling boundary

Registered standard D&D mechanics are engine-owned. Use the public settlement
tool and accept its arithmetic, resource payment, dice, and lifecycle result.
Do not reinterpret a standard mechanic as free-form module content.

For module-specific or homebrew semantics, retrieve exact source evidence.
When no registered implementation exists, the Agent acts as DM: reason from
the cited text, request `continuity_context(purpose="bounded_ruling")`, produce
the fixed proposal in a zero-tool bounded evaluation, validate it through
`bounded_evaluation`, and let the engine execute only its generic validated
operation.

Continue through ordinary `pending_ruling` results whose
`default_resolver="agent"`. Stop only for a player-owned choice, owner or
permission approval, or missing/conflicting source review. Search summaries are
discovery hints, not exact evidence.
