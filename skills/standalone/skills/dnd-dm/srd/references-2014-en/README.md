# D&D 5e 2014 SRD reference

This directory contains the repository-local Markdown adaptation of the D&D 5e
SRD 5.1 bundled with Standalone Skills. It supports local lookup only and does
not provide Full MCP authorization, campaign revisions, rule-profile locks,
ActorKnowledge, or authoritative settlement.

The corpus is derived from the upstream SRD reForged adaptation. Preserve the
adjacent `Legal.md`, repository NOTICE, attribution, and applicable license when
using or redistributing it. The upstream project's image, archive-download,
issue, and pull-request links are intentionally not reproduced here because
their original relative paths do not resolve inside this vendored layout.

Do not place commercial rulebooks, user uploads, generated model content, or
campaign data in this directory. Standalone writes remain local portable state
and never enter a Full MCP campaign.
